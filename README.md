# Bibliomancy Reading · 书占解读法

面向 AI Agent 的书占（bibliomancy）解读 Skill。带着一个问题随手翻开任意一本书，把翻到的一页当作一场正在发生的戏来读，而不是一句神谕。

它读的是：你在问什么；谁在场、谁在说、说给谁听；叙述者此刻知道多少、可不可靠；斗嘴、口误、双关这些情境中的语言；这一页有多重；人物处在自己故事的哪个时期。最后以“关系对关系”落回你的处境，把页面写了什么、你提供了什么、解读者在推测什么分开写。

读完之后，它会先问你哪里对上了、哪里读偏了，再给出几个在同一页上接着挖的方向。翻到的那一页已经作数，不重抽。

## 能读什么书

任何书。小说、诗集、杂文、回忆录、探案集都可以：克劳利的《忏悔录》，鲁迅的杂文，《神曲》，《福尔摩斯探案集》，《我的青春恋爱物语果然有问题》……

这套读法不绑定任何书目。配套的《物语系列》素材层（分页抽取、每一话的卡片、按时期分开的人物）正在制作中；有素材层时，它会把背景一并交给本 Skill。

## 安装

不需要脚本、联网或账号，只有一个 `SKILL.md`。

- **Claude Code**：把整个目录放到 `~/.claude/skills/bibliomancy-reading/`（或项目内的 `.claude/skills/`）
- **Codex**：放到 `.agents/skills/bibliomancy-reading/`
- 其他 Agent：让它从 `SKILL.md` 开始读取

## 使用

1. 想一个问题（没有也可以）
2. 随手翻开一本书，或者用任何随机方式定一个页码
3. 把问题和翻到的那一页文字交给 Agent，说“书占解读”或“帮我读这一页”

原文请自备；本仓库不包含任何书籍正文。
